# Trace

Shared monorepo baseline for the Trace web application, API, workers, packages, and infrastructure.

The training MVP now includes the authenticated web/API application, GitHub OAuth and App installation, repository tracking, signed webhook ingestion, durable workers, activity dashboards, report generation and revision, controlled LaTeX compilation, and owner-authorized artifact downloads. See `docs/backend-setup.md`, `docs/api.md`, and `docs/backend-security.md` for current setup, contracts, and operational boundaries; the reviewed plans remain historical sequencing records.
